## The short answer

Coding, or programming, means writing instructions that a computer can follow. These instructions are called code, and a set of them that does a job is a program.

Computers can't understand English or Hindi. Deep down, they only understand [patterns of 0s and 1s](zero-to-computers). So people write code in [programming languages](coding-languages), such as Python, JavaScript or Java, which use English-like words and strict rules. Special programs then translate that code into the 0s and 1s the computer's processor follows.

Every app, website, game and smart device runs on code that somebody wrote, tested and fixed.

## Languages for machines

A programming language is a bit like a human language with a very strict [grammar](grammar-why). Leave out a bracket or misspell a word and the computer refuses to run the program. It can't guess what you meant.

Different languages suit different jobs. Python is popular for science, data and learning to code. JavaScript makes websites interactive. C is used where speed matters, such as in the systems that run phones. Swift and Kotlin are used to build phone [apps](apps-made).

For younger learners, [Scratch](python-scratch), made at the Massachusetts Institute of Technology in 2007, uses colourful blocks that snap together like puzzle pieces, so you can make games without typing.

## Step by step

At its heart, coding means breaking a big job into tiny, exact steps. These step-by-step plans are called [algorithms](algorithms).

Programs use a few basic building blocks. Sequences do one thing after another. Loops repeat steps, such as "do this 100 times". Conditions make choices: "if the player touches a coin, add one point". Variables store information, like a score or a name. With just these pieces, programmers build everything from [calculators](calculators) to [video games](video-games).

Many programmers' first program simply makes the computer display "Hello, world". The tradition was made famous by a 1978 book about the C language.

## Code that went to the Moon

In 1969, the [Apollo 11 lunar module](moon-landing-sites) carried a small computer with code written by a team at MIT, led by Margaret Hamilton. As the module neared the Moon, alarms went off: the computer was overloaded. Because the software had been designed to drop less important tasks and focus on the most important ones, the landing could continue.

A famous photo shows Hamilton standing beside printouts of the Apollo code, stacked as tall as she was.

## Bugs and debugging

No one writes perfect code the first time. Mistakes in code are called bugs. A bug might make a game freeze, an app crash or a calculation come out wrong.

Programmers spend much of their time testing their code and hunting for bugs. They read error messages, add checks, and try the program in strange situations to see what breaks. Some say good programming is less about writing code and more about fixing it.

## Who codes, and where

Millions of people write code for a living. India is one of the largest centres of software work in the world. Cities like [Bengaluru](bengaluru), [Hyderabad](hyderabad) and Pune are home to huge numbers of programmers working for Indian and foreign companies. In the USA, [Silicon Valley](silicon-valley) in California is the best-known tech hub.

But coding isn't only for professionals. Scientists use it to study climate and disease. Artists use it to make music and pictures. Many schools in India and the USA now teach it, and children make their own games with Scratch. Code is a way of giving instructions, and anyone patient enough to learn its rules can write it.
