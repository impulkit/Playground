What are Scratch and Python?

Python, one of the world's most popular programming languages, is named after a British comedy show, not a snake.

The short answer

Scratch and Python are both programming languages, ways of giving instructions to a computer. Scratch is made for beginners, especially children. Instead of typing, you drag colourful blocks that say things like "move 10 steps" or "repeat 4 times" and snap them together to make games, animations and stories.

Python is a typed language, but it was designed to be easy to read. It is used by beginners and by professionals at big companies, space agencies and universities. Many people start with Scratch and move on to Python, because the big ideas are the same.

Surprising but true

Guido van Rossum started writing Python as a hobby project over the Christmas holidays at the end of 1989.

Scratch: coding with blocks

Scratch was created at the MIT Media Lab in the USA by a team led by Mitchel Resnick, and launched for free in 2007. Its mascot is an orange cartoon cat. You choose characters, called sprites, and give them instructions by stacking blocks. Click the green flag and the program runs. If the cat walks off the screen, you can see the mistake straight away and fix it.

The blocks are shaped like puzzle pieces. A block that needs a number has a round hole for it. A block that asks a yes-or-no question has pointed ends. Blocks only fit together in ways that make sense, so you can't make the kind of typing mistakes that trip up beginners in other languages.

Sharing and remixing

The Scratch website is also a huge online community. Tens of millions of young people around the world have shared projects there. Anyone can look inside a project to see how it works, and "remix" it to make their own version, with credit to the original maker.

Scratch is available in dozens of languages, including Hindi, Tamil, Bengali and Spanish, so children can code in the language they speak at home. A simpler version, ScratchJr, made for children aged about 5 to 7, runs on tablets.

Python: code that reads like English

Python was created by a Dutch programmer named Guido van Rossum. He began it as a hobby over the Christmas break in 1989 and released it in 1991. He named it after Monty Python's Flying Circus, a British comedy show, because he wanted the name to be short, unusual and a little silly.

Python is famous for being tidy. Spaces at the start of each line show which instructions belong together, so a Python program is laid out a bit like a well-organised list. Making a computer say hello takes just one line of code.

What people build with Python

Python is used for an enormous range of jobs, partly because volunteers have written thousands of free add-ons for it, called libraries. Scientists use it to analyse data from telescopes and gene studies. Websites use it behind the scenes. It is one of the main languages used to build artificial intelligence systems, and NASA engineers have used it to process data and run tests. In 2025, Python topped several popularity rankings of programming languages.

It is also widely taught in schools in India, the USA and elsewhere, because students can do real things with it quickly, from drawing shapes to building simple games.

Same ideas, different tools

Underneath, Scratch and Python teach the same thinking. You break a big problem into small steps, which is what an algorithm is. You repeat actions using loops. You make decisions with "if this, then that". You store information in variables, like a score in a game.

That is why moving from Scratch to Python feels less like starting over and more like swapping a bicycle with training wheels for a proper bike. And once you know Python, learning other coding languages becomes much easier.

Myth or fact?

Myth: Python got its name from the snake.

Truth: Its creator, Guido van Rossum, named it after Monty Python's Flying Circus, a British comedy show he enjoyed. The snake logo came later.

Try this

Be a robot programmer without a computer. Write instructions on cards, such as "step forward", "turn left" and "repeat 3 times", and give them to a friend or family member. Guide them from one side of a room to a chair using only your cards. If they bump into something, find the "bug" in your program and fix it.
